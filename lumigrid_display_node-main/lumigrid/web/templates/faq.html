🚀 Getting Started

Lumigrid Display Node is a Raspberry Pi-based LED matrix information display system. It allows you to display rotating content like time, date, temperature, humidity, and custom messages on an RGB LED matrix panel.

Key features include:

  • Web-based control panel accessible from any device
  • Frame-based content rotation system
  • Full customization of fonts, colors, and positions
  • Support for hzeller's rpi-rgb-led-matrix library
  • TTF font support with custom font upload

Required:

  • Raspberry Pi (any model with GPIO headers)
  • RGB LED Matrix panel (HUB75 compatible)
  • Power supply appropriate for your LED matrix (typically 5V)

Optional:

  • DS3231 or DS1307 RTC module for accurate timekeeping
  • DS18B20 (1-Wire) or DHT11/DHT22 temperature sensor
  • DHT22 also provides humidity readings

Follow these steps:

  1. Clone the repository: 
    git clone https://github.com/algorhythmicdev/lumigrid_display_node.git
  2. Run the installation script: 
    cd lumigrid_display_node
chmod +x install.sh
./install.sh
  3. Copy and edit the configuration: 
    cp config.yaml.example config.yaml
nano config.yaml
  4. Enable and start the service: 
    sudo systemctl enable lumigrid
sudo systemctl start lumigrid

⚙️ Display Settings

  • Rows: Height of a single panel (typically 16, 32, or 64)
  • Columns: Width of a single panel (typically 32, 64, or 128)
  • Chain Length: Number of panels daisy-chained horizontally
  • Parallel: Number of parallel chains (for larger displays)

For example, two 64x32 panels chained together would be: rows=32, cols=64, chain_length=2

  • regular: Default mapping for most setups
  • adafruit-hat: For Adafruit RGB Matrix HAT
  • adafruit-hat-pwm: For Adafruit HAT with hardware PWM
  • compute-module: For Raspberry Pi Compute Module

If unsure, start with "regular" and try "adafruit-hat" if you have an Adafruit HAT.

GPIO slowdown compensates for the faster GPIO on newer Raspberry Pi models. Recommended values:

  • Pi 1: 0
  • Pi 2: 1-2
  • Pi 3: 2-3
  • Pi 4: 4-5

If you see flickering or artifacts, try increasing this value.

If colors appear wrong (e.g., red shows as blue), adjust the RGB Sequence setting. Try different combinations:

  • RGB (default)
  • RBG
  • GRB
  • GBR
  • BGR
  • BRG

The correct setting depends on your specific LED panel's wiring.

Most panels use "Direct (0)". If you see scrambled pixels, you may need a different multiplexing type. Common alternatives:

  • Stripe (1): For some outdoor panels
  • Checker (2): For checkerboard pattern panels
  • P10 types: For P10 outdoor LED modules

Check your panel's documentation or experiment to find the correct setting.

🎨 Frames & Content

The Frame system allows you to create multiple display "frames" that automatically rotate in sequence. Each frame can display different content (time, date, temperature, etc.) with its own styling.

For example, you could have:

  • Frame 1: Large clock display for 10 seconds
  • Frame 2: Current temperature for 5 seconds
  • Frame 3: Today's date for 5 seconds
  • Frame 4: Custom message for 3 seconds
  • Time: Displays current time (customizable format)
  • Date: Displays current date (customizable format)
  • Date & Time: Displays both date and time
  • Temperature: Shows temperature from sensor (°C or °F)
  • Humidity: Shows humidity from DHT sensor (%)
  • Custom Text: Display any text you want

Use Python strftime format codes:

  • %H - 24-hour (00-23)
  • %I - 12-hour (01-12)
  • %M - Minute (00-59)
  • %S - Second (00-59)
  • %p - AM/PM
  • %Y - Year (2024)
  • %m - Month (01-12)
  • %d - Day (01-31)
  • %A - Weekday name (Monday)
  • %B - Month name (January)

Examples:

  • %H:%M:%S → 14:30:45
  • %I:%M %p → 02:30 PM
  • %Y-%m-%d → 2024-01-15
  • %A, %B %d → Monday, January 15

Go to the Content & Frames page and use the Font Management section:

  1. Click the upload area or drag a TTF/OTF font file
  2. The font will be uploaded and available immediately
  3. Select it when editing a frame's appearance

Note: Only TTF and OTF font files are supported.

🔧 Troubleshooting

  • Check power supply - LED matrices need adequate power
  • Verify GPIO connections
  • Try different hardware_mapping settings
  • Adjust gpio_slowdown for your Pi model
  • Check the multiplexing setting
  • Verify rows and cols match your panel

For DS18B20 (1-Wire):

  • Enable 1-Wire in /boot/config.txt: dtoverlay=w1-gpio
  • Reboot after enabling
  • Check if detected: ls /sys/bus/w1/devices/
  • Ensure 4.7kΩ pull-up resistor between data and VCC

For DHT11/DHT22:

  • Verify GPIO pin in config matches physical connection
  • Check 10kΩ pull-up resistor (some modules have built-in)
  • DHT sensors can be slow - wait a few seconds between reads
  • Check if service is running: sudo systemctl status lumigrid
  • Verify port in config (default: 5000)
  • Try accessing locally first: http://localhost:5000
  • Check firewall settings
  • View logs: sudo journalctl -u lumigrid -f
  • Increase GPIO Slowdown value
  • Reduce PWM Bits (try 8 or 9 instead of 11)
  • Check power supply - insufficient power causes flickering
  • Try disabling WiFi/Bluetooth to reduce CPU interference
  • Use a quality power supply with adequate amperage
  • Verify I2C is enabled: sudo i2cdetect -y 1
  • DS3231/DS1307 should appear at address 0x68
  • Check physical connections (SDA to GPIO 2, SCL to GPIO 3)
  • Replace the RTC battery if it's old

📡 API Reference

Status & Control:

  • GET /api/status - System status
  • GET/POST /api/mode - Display mode
  • GET/POST /api/brightness - Brightness control
  • POST /api/message - Send custom message

Sensors:

  • GET /api/temperature - Current temperature
  • GET /api/humidity - Current humidity

Configuration:

  • GET/POST /api/config - Full configuration
  • GET/POST /api/led-matrix - Matrix settings
  • GET/POST /api/network - Network settings

Frames:

  • GET/POST /api/frames - List/create frames
  • GET/PUT/DELETE /api/frames/{id} - Manage frame
  • POST /api/frames/reorder - Reorder frames
  • POST /api/frames/{id}/toggle - Enable/disable

Fonts:

  • GET /api/fonts - List fonts
  • POST /api/fonts/upload - Upload font
  • POST /api/fonts/delete - Delete font
