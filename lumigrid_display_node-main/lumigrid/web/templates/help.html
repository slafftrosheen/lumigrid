🔌 Hardware Requirements

Required Components

  • Raspberry Pi - Any model with GPIO headers (Pi 3, 4, or 5 recommended)
  • RGB LED Matrix - HUB75-compatible panel (16x32, 32x32, 32x64, or 64x64 pixels)
  • Power Supply - 5V power supply appropriate for your LED matrix size (typically 5-10A)
  • MicroSD Card - 16GB or larger with Raspberry Pi OS installed

Optional Components

  • DS3231 RTC Module - For accurate timekeeping without internet connection (I2C)
  • DS18B20 Temperature Sensor - 1-Wire temperature sensor
  • DHT11/DHT22 Sensor - Temperature and humidity sensor
💡 Tip: For detailed wiring diagrams and setup instructions, see the Hardware Setup Guide.

💾 Operating System Setup

Prerequisites

  1. Install Raspberry Pi OS (Bullseye or later) on your microSD card
  2. Enable SSH for remote access (optional but recommended)
  3. Connect your Raspberry Pi to your network (WiFi or Ethernet)
  4. Update your system: 
    sudo apt update && sudo apt upgrade -y

Enable Required Interfaces

Use sudo raspi-config to enable:

  • I2C - For RTC module (Interface Options → I2C → Enable)
  • 1-Wire - For DS18B20 sensor (Interface Options → 1-Wire → Enable)

📥 Installation Guide

Quick Installation

  1. Clone the repository: 
    git clone https://github.com/algorhythmicdev/lumigrid_display_node.git
cd lumigrid_display_node
  2. Run the installation script: 
    chmod +x install.sh
./install.sh
  3. Wait for installation to complete (10-15 minutes)
  4. Edit the configuration file: 
    nano config.yaml
  5. Enable and start the service: 
    sudo systemctl enable lumigrid
sudo systemctl start lumigrid
📖 More Info: For manual installation and troubleshooting, see the Quick Start Guide.

🔧 Troubleshooting Guide

Display Issues

Display Shows Nothing or Garbage

  • Check power supply - LED matrices need adequate power
  • Verify GPIO connections match wiring diagram
  • Try different hardware mapping settings (regular, adafruit-hat)
  • Adjust GPIO slowdown for your Pi model (Pi 4 = 4-5, Pi 3 = 2-3)
  • Check multiplexing setting matches your panel type

Wrong Colors Displayed

  • Adjust RGB Sequence setting (try RGB, RBG, GRB, GBR, BGR, BRG)
  • The correct setting depends on your panel's wiring

Flickering or Artifacts

  • Increase GPIO Slowdown value
  • Reduce PWM Bits (try 8 or 9 instead of 11)
  • Check power supply - insufficient power causes flickering
  • Ensure service is running with sudo (for proper GPIO access)

Sensor Problems

Temperature Sensor Not Reading

For DS18B20 (1-Wire):

  • Enable 1-Wire in /boot/config.txt: dtoverlay=w1-gpio
  • Reboot after enabling
  • Verify detection: ls /sys/bus/w1/devices/
  • Check 4.7kΩ pull-up resistor between data and VCC

For DHT11/DHT22:

  • Verify GPIO pin in config matches physical connection
  • Check 10kΩ pull-up resistor (some modules have built-in)
  • DHT sensors can be slow - wait a few seconds between reads

RTC Not Keeping Time

  • Verify I2C is enabled: sudo i2cdetect -y 1
  • DS3231/DS1307 should appear at address 0x68
  • Check physical connections (SDA to GPIO 2, SCL to GPIO 3)
  • Replace RTC battery if old

Network Connectivity

Web Interface Not Accessible

  • Check service status: sudo systemctl status lumigrid
  • Verify port in config (default: 5000)
  • Try accessing locally first: http://localhost:5000
  • Check firewall settings
  • View logs: sudo journalctl -u lumigrid -f

UDP Sync Not Working

  • Verify all nodes are on the same network/subnet
  • Check UDP port is open (default: 9876)
  • Ensure firewall allows UDP traffic on sync port
  • Verify master node is broadcasting

Performance Issues

  • Close unnecessary applications on the Pi
  • Disable WiFi/Bluetooth if not needed to reduce CPU load
  • Use a quality power supply with adequate amperage
  • Consider using isolcpus boot parameter for better timing

📡 REST API Reference

The LumiGrid Display Node provides a comprehensive REST API for programmatic control.

Quick API Examples

Get System Status

curl http://your-pi-ip:5000/api/status

Set Display Mode

curl -X POST http://your-pi-ip:5000/api/mode \
  -H "Content-Type: application/json" \
  -d '{"mode": "clock"}'

Adjust Brightness

curl -X POST http://your-pi-ip:5000/api/brightness \
  -H "Content-Type: application/json" \
  -d '{"brightness": 75}'

Create a Frame

curl -X POST http://your-pi-ip:5000/api/frames \
  -H "Content-Type: application/json" \
  -d '{
    "type": "time",
    "name": "Red Clock",
    "enabled": true,
    "duration": 10,
    "colors": {"text": "#FF0000", "background": "#000000"},
    "font": {"path": "Minimal.ttf", "size": 16}
  }'
📖 Complete API Reference: See the API Documentation for all endpoints, schemas, and examples.

💻 API Usage Examples

Python Example

import requests

# Get status
response = requests.get('http://your-pi-ip:5000/api/status')
print(response.json())

# Create a preset
preset = {
    "preset_name": "blue_clock",
    "frame_config": {
        "type": "time",
        "colors": {"text": "#0000FF", "background": "#000000"}
    }
}
response = requests.post('http://your-pi-ip:5000/api/presets', json=preset)
print(response.json())

JavaScript Example

// Get current temperature
fetch('http://your-pi-ip:5000/api/temperature')
  .then(response => response.json())
  .then(data => console.log('Temperature:', data.temperature))
  .catch(error => console.error('Error:', error));

// Set brightness
fetch('http://your-pi-ip:5000/api/brightness', {
  method: 'POST',
  headers: {'Content-Type': 'application/json'},
  body: JSON.stringify({brightness: 50})
})
  .then(response => response.json())
  .then(data => console.log('Success:', data));
📖 More Examples: See the Examples Documentation for integration patterns and use cases.

🔌 ESP32 Integration Guide

LumiGrid Display Nodes can integrate with ESP32 LED nodes for coordinated lighting systems.

Key Integration Features

  • UDP Synchronization - Keep all nodes in perfect sync
  • Preset Schema Alignment - Share compatible presets between devices
  • Sensor Data Bridging - ESP32 sensors → Pi displays
  • Coordinated Effects - Synchronized animations and colors

Quick Integration Example

// ESP32 sending sensor data to Display Node
#include <HTTPClient.h>

HTTPClient http;
http.begin("http://display-node:5000/api/sensor_update");
http.addHeader("Content-Type", "application/json");

String payload = "{\"node_id\":\"esp32-01\",\"readings\":{\"temperature\":23.5}}";
int httpCode = http.POST(payload);
http.end();
📖 Complete Integration Guide: See the ESP32 Integration Documentation for detailed setup instructions and examples.

🔄 UDP Synchronization Protocol

Sync Modes

  • Standalone - Operates independently
  • Master - Broadcasts sync commands to slave nodes
  • Slave - Receives and follows master commands

Configuration

Configure sync settings in the Network page:

  • Set Control Mode to "Sync Master" or "Sync Slave"
  • Configure UDP port (default: 9876)
  • Set master IP address (for slave nodes)
📖 Protocol Details: See the UDP Synchronization Documentation for protocol specification and troubleshooting.

📦 Project Overview

LumiGrid Display Node is a comprehensive Raspberry Pi-based LED matrix information display system.

Key Features

  • LED matrix display powered by hzeller's rpi-rgb-led-matrix library
  • Real-time clock (RTC) support for accurate timekeeping
  • Temperature and humidity sensor integration
  • Modern, responsive web interface
  • Timeline-based scheduling system
  • UDP synchronization for multi-node displays
  • Frame-based content system with custom presets
