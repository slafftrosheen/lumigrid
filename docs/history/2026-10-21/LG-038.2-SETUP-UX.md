# LG-038.2 & LG-038.7 Setup & Authentication Reference

FactoryFirstBoot uses `LumiGrid-Setup` with a random per-device Wi-Fi WPA2 password
generated via hardware RNG (`esp_fill_random`) and displayed on serial console.
There are no universal credentials and no MAC-derived passwords.

Permanent AuthStore credentials require 16–64 characters.
The bootstrap endpoint (`POST /api/v1/auth/bootstrap`) is state-gated:
it is accessible without authentication ONLY while `!is_provisioned()` and
`bootstrap_allowed()` (genuine `FactoryFirstBoot` or `PhysicalRecovery`).

`POST /api/v1/auth/bootstrap` saves the permanent Admin key and returns a new
Admin session in the same request. NVS backup and commit errors are propagated.
Invalid existing auth storage fails closed instead of being interpreted as
first boot.

Both dashboards detect first setup, request a new confirmed Admin key and
continue directly into setup. Both offer key generation and Access account
management without displaying saved secrets.
