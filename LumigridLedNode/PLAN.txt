1. Market Context & Hardware Positioning
Reclame Fabriek (your lander parent) builds physical LED signage for commercial clients. The algorhythmicdev.github.io/lumigrid-lander/ domain is currently 404 — the lander isn't deployed yet. This is actually good: you control the narrative from day one.

What pro signage clients actually need:

Day/night dimming schedules (signs must dim at 10 PM automatically)
Emergency "all off" / "all red" panic buttons
Scene recall (corporate brand colors, holiday themes, "sale mode" flashing)
Content scheduling (play this animation at 6 PM on Friday)
Status monitoring (is the sign dead? Is it overheating?)
Remote management (dim from a phone, change schedule without a ladder)
DMX/ArtNet integration (sync with existing venue lighting consoles)
"No touch" operation — once installed, nobody touches the ESP settings
WLED's current positioning is WiFi-LED-controller-for-hobbyists. It has most of the guts, but the UX and defaults target LED strip tinkerers, not sign installers.

3. The Three-Layer Problem
WLED gives you Layer 1 (LED control) but not Layer 2 (signage orchestration) or Layer 3 (professional operator UX).

Layer 3 — Signage UX (MISSING) • Scheduling, scenes, emergency controls, remote management, CMS timeline • Operator-focused web UI (not hobbyist-focused) • Monitoring dashboard

Layer 2 — Pro Hardware Bridge (PARTIAL) • PCA9685 channel mapping & config UI • GPIO button handling (emergency stop, mode toggle) • I2C device discovery (auto-detect PCA9685) • Watchdog / auto-recovery

Layer 1 — LED Control (PRESENT) • WLED core + effects + WiFi + OTA

4B. Build Out PCA9685 Usermod (usermods/lumigrid_pca9685/)
Today: Blind color mapper, no UI. Target: Configurable 16-channel PWM controller with per-channel mode selection.

New UI additions needed in appendConfigData():

16 dropdown selects: Off / Dumb PWM / CCT / RGB / RGBW
Per-channel label field (e.g., "Warm White Strip", "Red Accent")
Save/Load to macros.json for preset scenes
Auto-detect I2C address (scan for 0x40–0x4F)
Expansion: support second PCA9685 (32 channels = 8 CCT fixtures)
New hardware features:

GPIO0 / GPIO button: short press = power toggle, long press = emergency all-off
I2C error watchdog: if PCA9685 stops responding, log and retry
Temperature sensor (e.g., DS18B20 on GPIO) → throttle brightness if overheating
